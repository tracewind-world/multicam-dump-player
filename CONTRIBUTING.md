# Contributing

Thanks for looking. This tool does one thing, so contributions are most useful when they keep it that way.

- **A new layout** (another recorder that puts many cameras in one file): open an issue first with a sample you have the right to share, or send a pull request that adds a reader next to `multicam_dump/luodat.py` and a test using a small sample.
- **Fixes**: keep them small, add a test, run `python -m unittest discover -s tests`.
- Be explicit about what is measured and what is a guess; the alignment is an estimate, and the code and docs say so.
- By contributing you agree that your contribution is licensed under Apache-2.0, the same as the rest of the project.

Maintained by [Tracewind](https://tracewind.world/). We answer issues, but not on a schedule.
