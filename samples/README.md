# Sample

`file0000.dat` — the first 8 MiB (8,388,608 bytes) of a 16-camera recorder dump, an old recording from a decommissioned system
(on-screen date 2013-12-05). Provided by its owner for use as a test sample in this repository.

- 16 cameras, 352×288, 16 fps, H.264, no audio.
- It is a piece cut out of a longer file, so it ends in the middle of the data (the parser reports that).
- It shows people and a street in low resolution. If you are, or know, someone in these pictures and want it removed, please open an issue.
